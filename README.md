# frogger-lite

终端青蛙过河小游戏：躲汽车、乘木头、到达 5 个目标。纯标准库，无第三方依赖。

## 玩法

```
   0123456789012
 9 ░★░░★░★░░★░★░   ← 终点岸：把青蛙送上 ★
 8 ≡≈≈≡≡≡≈≈≈≈≈≡≡
 7 ≡≡≈≈≈≈≈≈≈≡≡≡≡   ← 河流：站在 ≡ 木头上，无木头则淹死
 6 ≡≡≈≡≡≡≈≡≡≡≈≈≡     （站在木头上会随木头漂移）
 5 ░░░░░░░░░░░░░   ← 中间岸（安全）
 4 ····▓▓▓······
 3 ▓▓·······▓▓··   ← 马路：▓ 是小车，撞到即死
 2 ▓▓▓▓▓···▓▓···     （车也会在 tick 时撞上青蛙）
 1 ▓▓▓·····▓▓··▓
 0 ░░░░░░░░░░░░░   ← 起点岸（安全）
```

- `w/a/s/d` 移动，`q` 退出；3 条命
- 到达一个 ★ 得 100 分，5 个全到则胜利
- 车道/河道每步随机生成（`--seed` 可复现）

## 用法

```bash
python3 -m frogger_lite              # 交互模式（需要终端）
python3 -m frogger_lite --auto       # 无头演示：贪心 AI 自动玩
python3 -m frogger_lite --auto --seed 42 --moves 400
```

## 设计取舍

- 回合制（每步一 tick），不是实时动作游戏——小巧起见
- 木头/小车用周期性 pattern 表示，`tick()` 统一滚动
- 车撞判定是双向的：青蛙跳进车里死，车开到青蛙身上也死
- `--auto` 是**一步前瞻贪心 AI**（deepcopy 模拟走子+tick，掉命重罚），
  不是最优玩家；Frogger 本来就难，AI 偶尔阵亡是如实演示

## 真实验证记录

- `py_compile`：通过
- 单元测试 6 项全过：被车撞死 / 乘木头漂移（位置随木头速度移动）/
  河里无木头淹死 / 到达目标 +100 / 五目标胜利 / 三命用完阵亡
- `--auto` 5 个种子：全部正常结束并打印目标/得分/步数（2/5 到达 1 个目标）
- 非 tty 直接运行：中文提示并 exit 2

## 已知局限

- 无实时键盘输入：交互是"每行一个命令"的回合制
- `--auto` AI 只是贪心演示，经常 0 分、偶尔阵亡，不是用来刷分的
- 无最高分存档、无难度分级、无音效
- 需要 Python 3.10+
